## Summary

Pointwest-North America is seeking a Senior Cloud Engineer with deep expertise in Amazon Web Services (AWS). The role designs, architects, implements, and maintains secure, scalable, and resilient cloud infrastructure while establishing cloud governance, automation, observability, migration, and Infrastructure-as-Code standards. The engineer will also provide technical leadership, collaborate across teams, and support incident response and on-call operations.

## Core responsibilities

- Design, architect, build, and maintain secure and scalable AWS infrastructure in a multi-account hybrid environment based on AWS Organizations practices
- Develop and enforce cloud architecture standards, best practices, and governance policies
- Implement and maintain infrastructure delivery pipelines to enable reliable and scalable cloud operations, collaborating with Software Engineering teams and leveraging AWS services
- Automate infrastructure provisioning, configuration, and monitoring using tools like Terraform, and AWS Cloud native services
- Collaborate with cross-functional teams including DevOps, Security, and Software Engineering teams to ensure cloud solutions meet business and compliance requirements
- Monitor cloud environments for performance, cost optimization, and security compliance
- Provide technical leadership and mentorship to junior engineers
- Participate in incident response and root cause analysis for cloud-related issues
- Stay current with AWS services and industry trends to drive continuous improvement
- Share 7x24 rotational responsibilities for On-Call support
- Work with the Security and Compliance teams regarding risk mitigation
