## Summary

Yahoo is a technology company that connects brands and partners with large audiences through digital platforms and services. Yahoo is seeking a Senior Software Development Engineer to own and advance its enterprise Node.js development environment, including runtimes, packages, container images, CI/CD workflows, and internal integrations. The role also supports source code management, AI programming tools, automation, troubleshooting, documentation, and collaboration across engineering teams.

## Core responsibilities

- Own the lifecycle of Yahoo’s supported Node.js runtimes, including adopting new releases and retiring end-of-life versions
- Build and maintain Node.js packages, container images, internal-library integrations, and automated release pipelines
- Develop and support reusable CI/CD and GitHub Actions workflows for Node.js applications and libraries
- Monitor upstream releases, security updates, and dependency changes, translating them into timely platform updates
- Troubleshoot complex runtime, build, packaging, container, and dependency issues affecting engineering teams
- Automate platform maintenance, testing, release validation, and other recurring operational work
- Partner with security, operating system, container, CI/CD, and application teams on platform changes and migrations
- Support the team’s GitHub Enterprise and GitLab Enterprise services and develop tools that improve the source code management experience
- Use and help integrate AI programming tools such as Claude AI and Claude Code, Cursor, and GitHub Copilot to improve engineering productivity and automate development workflows
- Document platform operations and clearly communicate releases, migrations, deprecations, and required actions to internal users
- Adhering to Yahoo policies; exercising sound judgment; working effectively, safely and inclusively with others; exhibiting trustworthiness and meeting expectations; and safeguarding business operations and brand integrity
