## Summary

UST is a mission-driven technology company that transforms businesses and lives through innovation, agility, and human-centered solutions. The AWS Cloud Architect will lead the end-to-end architecture and execution of on-premises to AWS migrations, including target-state design, application migration strategies, infrastructure, CI/CD, security, observability, and certificate management. The role also provides hands-on technical guidance throughout build and cutover phases.

## Core responsibilities

- Own the target-state AWS architecture for the on-premises to AWS migration across the application portfolio
- Assess existing on-prem applications — Liferay, SiteCore, PingFederate, ETL jobs, Angular/Node.js services — and define per-application migration strategy (rehost, replatform, refactor)
- Design AWS infrastructure and integration patterns for portal/CMS platforms (Liferay, SiteCore) and identity/SSO (PingFederate)
- Architect migration and re-platforming of ETL jobs onto AWS-native or AWS-compatible data processing services
- Define CI/CD pipelines and DevOps practices (build, test, deploy, containerization) for migrated applications
- Establish cloud engineering standards, guardrails, and reference architectures for teams to follow during migration
- Lead technical design reviews, migration runbooks, and cutover planning across application teams
- Partner with security and DevSecOps to ensure migrated applications meet compliance and security requirements
- Provide hands-on architectural guidance and troubleshooting support during build and cutover phases
- Define and implement the observability strategy for migrated applications using Dynatrace
- Design certificate management architecture using AWS Certificate Manager (ACM) for migrated applications and load balancers
